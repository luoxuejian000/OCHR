# OCHR 1.0 —— 流形计算引擎原型

基于**晶脉哲学**与**谐振理论**构建的下一代 AI Agent 集群框架。OCHR v2.0 不再是一个外挂的治理工具——它直接运行在一个显式的**流形计算引擎**之上。

## 核心思想

传统 Agent 框架将大模型视为“智能中心”，工具和程序代码是其附属品。OCHR v2.0 彻底颠覆了这一范式：

**Agent、工具、资源不再是孤立的实体，而是流形上的动子（Mover）。它们的协作、冲突、调谐不再是外部监控，而是流形内部的几何运算。**

## 核心概念

| 概念 | 定义 | 在 OCHR 中的实现 |
|------|------|-----------------|
| **动子 (Mover)** | 流形上的基本存在单元，无固有属性，只有位置和状态向量 | `Manifold` 类管理所有动子 |
| **触 (Taction)** | 有向的因果关系，时间之矢的微观根源 | Agent 处理任务时创建的因果边 |
| **缠 (Entwinement)** | 无向的共存关系，空间共时性的微观根源 | 动子之间的对称关系边 |
| **展 (Unfold)** | 从一个动子出发，沿关系边追踪 N 步 | `Manifold.unfold()` 方法 |
| **象 (Appearance)** | 展的宏观粗粒化投影 | 和谐度 H 值作为流形状态的宏观指标 |

## 哲学公理

OCHR v2.0 的每一行代码都可以追溯到晶脉哲学的四重公理：

| 公理 | 核心命题 | 工程实现 |
|------|---------|---------|
| **关系本体论** | 一切皆动子，存在即关系 | `Manifold` 流形内核，动子由关系网络定位 |
| **矛盾动力论** | 矛盾是场域内部的几何张力，驱动系统演化 | `detect_contradictions()` 基于向量几何的张力计算 |
| **实践介入论** | 每一次评估都是对场域的介入，介入痕迹必须可审计 | `ReflectionCavity` 映照腔记录因果链 |
| **谐振调谐论** | 系统朝向更高和谐度自组织，权重可协商 | `HarmonyEngine` + `WeightNegotiation` |

## v2.0 升级亮点

| 模块 | v1.0 | v2.0 |
|------|------|------|
| **矛盾捕获器** | 基于正则匹配的工具调用冲突检测 | 基于流形几何向量的关系张力检测 |
| **SNI** | 统计型自我叙事（“我擅长X”） | 因果型自我叙事（“A值升高是因为资源Y上的冲突”） |
| **映照腔** | 状态快照（“A值变了”） | 因果快照（“A值变了，因为动子X和动子Y的向量偏离”） |
| **边界管理器** | 被动降级（A值超标才触发） | 自适应收缩（主动识别高张力区域并提前收紧） |
| **集群调度器** | 利用导向（总是选最擅长节点） | 探索-利用动态平衡（温度参数自适应） |
| **计算基底** | 无（外部指标驱动） | 🆕 显式流形计算引擎（`Manifold` 内核） |

## 配置

所有权重参数均为“协商起点”，可通过 `config.py` 或环境变量覆盖：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `LAMBDA_U` | 0.4 | 统一性权重 |
| `LAMBDA_D` | 0.3 | 发展性权重 |
| `LAMBDA_A` | 0.3 | 对抗性权重 |
| `LAMBDA_C` | 0.1 | 成本权重 |

## 边界坦陈

**OCHR v2.0 能做的：**
- 在流形场域中自动检测节点间的关系张力
- 生成具有因果追溯能力的自我叙事和审计报告
- 根据张力分布自适应调整安全边界和任务调度
- 为构建完整的“流形计算引擎”提供工程验证

**OCHR v2.0 不能做的：**
- 消除所有不安全（安全是场域内部的持续博弈）
- 替代人类最终决策（系统提供诊断和建议，责任仍属人类）
- 让Agent集群永不犯错（泛化与不确定性同源）
